# Código de Conducta

## Nuestro compromiso

Este proyecto existe para ayudar a personas en medio de una emergencia
real. Esperamos de cualquier persona que participe:

- **Respeto**, incluso en desacuerdo sobre una fuente o un dato.
- **Precisión sobre velocidad** cuando se trate de cifras de víctimas o
  canales de donación — un error aquí tiene costo real para alguien.
- **Cero tolerancia a contenido usado para desinformar, estafar o explotar
  la emergencia** (canales de donación falsos, cifras infladas o
  minimizadas a propósito, spam, autopromoción no relacionada).
- **Transparencia** sobre fuentes: si no puedes verificar un dato, dilo,
  no lo presentes como confirmado.

## Aplicación

Las personas mantenedoras pueden eliminar, editar o rechazar
contribuciones que no sigan estas reglas, y bloquear a quien las viole de
forma repetida. Para reportar un problema, abre un issue marcado como
`conducta` o contacta directamente a quienes mantienen el repositorio.
